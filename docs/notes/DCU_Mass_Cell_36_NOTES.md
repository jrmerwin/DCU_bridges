# Cell 36 — a protected collective memory and a state-sensitive interface

## Result and status

The balanced four-path attachment supports logical operations and an explicit
ideal joint-label measurement without destroying any of its three phase-word
states. Protection against its storage noise is compatible with such a responsive
interface. However, the current native growth/recording-work kernel is exactly
independent of those encoded labels. The ideal measurement circuit is an added
controlled quantum interaction, not a native constructor operation.

There is a consequential distinction between two readout implementations with
identical three-outcome probabilities: separate local Fourier measurements,
followed by reporting their difference, disturb the protected memory; a coherent
measurement of the difference alone can preserve it. The supplied probability
kernel does not uniquely choose a post-measurement state-update map.

The same coherent measurement decomposed into two local controlled shifts is
vulnerable to a native phase-driving event between the shifts. This gives an
explicit implementation target, not a claim that an autonomous native meter has
already been built.

No stochastic growth trajectories, mass formulas, energy values, SI calibration,
regional service pool, observer identity rule or neutron-search operation is added.
All quantum operations remain conditional on the inherited complex representation.

## 4. Same outcome statistics, different measurement disturbance

The source supplies phase/Fourier probabilities. To examine disturbance we must
state a measurement instrument, not infer it from those probabilities alone.

For the explicit rank-one LOCAL projective implementation, let |a_A> and |b_B>
be the opposite-exponent local Fourier vectors. For input Omega_k, only outcomes
b-a=k mod3 occur, each with probability1/3. The conditional memory becomes the
product |a_A>|b_B>. Its overlap with the original Omega_k is1/3, its weight in C
is1/3, and its entanglement negativity is zero. Averaging the retained branches
gives the same fidelity and code weight; it is an explicit separable mixture.
No physical gate cost or irreversible-collapse hypothesis is inferred.

Knowing the word perfectly therefore does not mean preserving the stored state.
Immediately repeating the same local measurement can repeat its local outcomes;
that is not proof that the original protected code survived subsequent storage.

Let

    Pi_k = sum_{b-a=k} |a_A,b_B><a_A,b_B|.

These are orthogonal rank-three projectors on the full nine-dimensional memory
space and sum to I. Coarse statistics alone are Tr(Pi_k rho) for either of two
instruments:

    fine local instrument, labels grouped: sum_{b-a=k} P_ab rho P_ab;
    coherent coarse instrument:             Pi_k rho Pi_k.

They have the SAME three-outcome POVM for EVERY input rho, but different
post-measurement states. The coarse instrument preserves Omega_k exactly.
The point is not to pick whichever update is favorable: the probability formula
does not supply the missing physical implementation or the cost of either update.
