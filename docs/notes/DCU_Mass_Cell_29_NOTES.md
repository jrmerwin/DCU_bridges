# Cell 29 — controlled native recording and clock/readout back-action

## Result and scope

One **conditioned legal native service event** creates a comparison record and its ordinary ancestry-recording obligations. Subsequent unmodified service histories drive the already adopted two-sibling phase readout. New recording reduces every old token's next service probability by an exactly calculable common factor. The finite continuations produce a corresponding difference in accumulated tagged services and interference, with substantial recovery in the relief-enabled setting.

This is a conditional cause-and-effect model calculation, not experimental evidence, physical gravitational redshift, an energy valuation, a new particle, or an autonomous observer selecting measurements. The nuclear search is unchanged. No new native phase-gate cost or phase dynamics is introduced.

## Three arms at each checkpoint

All arms use Gamma=3,m=0 and condition ONE service selection on exactly two designated old maintenance tokens and one actual forced token. The probability of selecting that maintenance pair and any one forced token in the unconstrained next service is F/binomial(F+n,3), identical for the eligible pairs at that checkpoint. Subsequent draws are ordinary random service. Conditioning is not presented as a free, physically implemented control operation.

- `existing_pair`: serve primitives 0,1. Their comparison already exists, so no child forms. No duplicate is attempted. Two maintenance services and one forced service still occur, including normal relief.
- `recorded_pair`: first lexicographically ordered absent pair of nonprimitive, already-recorded endpoints, excluding clock carriers 3,4.
- `first_use_pair`: first corresponding absent pair with exactly one recorded and one unrecorded endpoint, also excluding carriers 3,4.

Ordering uses recursively specified primitive-labeled parentage strings, not the cost, effect, mass residual, or particle labels. Thus this is an apparatus-oriented pilot, not a relabeling-invariant species definition. Both new-comparison arms retain EVERY enabled child; because exactly two maintenance endpoints are served, the only enabled absent pair is that pair. The native function handles the whole event.

At the end of the event the old parentage and inclusive ancestries are unchanged. The outstanding work, added child, first-write status and complete prior maintenance counts remain. Attached phase/readout counters are initialized for the common controlled observation window AFTER this event. This is not erasure of native history. The sibling tokens are not selected during any conditioning event.

## Exact immediate prediction

Let R0=F_control+n_control be the token count after the conditioned existing-pair event, and C the newly generated cost of a comparison. Both interventions consume the same number of forced/maintenance tokens and apply the same pre-construction relief. The new comparison adds C work requests plus ONE new maintenance token:

    R_write = R0 + C + 1.
    p_control = 3/R0.
    p_write/p_control = R0/(R0+C+1).

For any fixed old pair, E[Delta K]=2p. Therefore the same ratio applies to the tagged clock's mean phase-increment rate per service opportunity. Values are 708/973 and 236/471 at H0; 366/659 and 366/1117 at H6.

The response is uniform over ALL old tokens, independent of ancestry distance, sector or status. It is a common service-pool effect, not a local field or finite-speed signal.

For the two-clock count K, p2=6/[R(R-1)] and

    P(Delta K=0)=1-2p+p2,
    P(Delta K=1)=2(p-p2),
    P(Delta K=2)=p2.

Every arm's law is checked by summing all maintenance subsets with the exact number of forced-token completions. First and second harmonic updates follow from this distribution; an independent hypergeometric calculation verifies all six laws. Co-service probabilities are not replaced with independent Bernoulli draws.

## Full native continuations

Each of six arms receives 512 fixed continuations, seeds 20290920..20291431, for 1024 updates. Seed integers are labels, not dates. Checkpoints are 0,1,8,32,128,512,1024. The total is 3,145,728 post-intervention native updates. No history is dropped. Each arm uses the same numbered RNG starts; subsequent state-dependent draws diverge. Paired differences and their Monte Carlo standard errors are calculated on these specified seed pairings, not as independent experimental samples.

All ledgers are checked pathwise:

    F=F_start+sum(cost)-sum(forced_service)-sum(relief),
    P=P_start+2sum(forced_service)-sum(relief),
    tau+sum(forced_service)=3t.

No deterministic approximation replaces the changing workloads or graphs.

## Interference readout

K=N3+N4 drives the inherited source:

    P_s=L(K/3^d-s/3), L(x)=(1+2cos(2pi x))^2/9.

Both coherence harmonics and mean probabilities are stored. Each time point is a separate counterfactual terminal readout, not repeated projective measurement during a single evolution. Persistent-value writes are not replaced by arbitrary register flips. The original spectator phase-retention assumption remains in force.

At H0 and 128 steps, the primary mean P0 is 0.874430, 0.933685, 0.965694 (control, recorded, first use). At 1024 it is 0.100638, 0.083722, 0.096407. Slower phase accumulation need not raise P0; the kernel is periodic/nonlinear. No damping, visibility or noise coefficient was fitted. More recording is not automatically more irreversible quantum decoherence.

## What an internal clock comparison sees

For reference B=N0+N1, all four old tokens have the same conditional probability, hence E[Delta(K-B)|history]=0. Both are slowed equally at the immediate-response level. Also with chi=sum(s_t/n_t), using pre-service n_t, E[K-2chi]=0 at a fixed finite horizon. All six observed residuals and standard errors are retained.

This is not proof that every higher-order phase statistic of all possible clocks is identical. It establishes an equal conditional drift and excludes an interpretation of this PARTICULAR mean-rate effect as a relative local redshift. The iteration index is not an identified observer clock or seconds. There is no native communication travel time in the experiment.
