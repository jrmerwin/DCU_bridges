# DCU bridges: manuscript and reproducible calculations

**From Registry Structure to Physical Observables**  
*Horizontal Transfers and Operational Bridges in the Distinction Combinatorial Universe*  
Jason Merwin · Working manuscript 0.1 · September 2026

This repository-ready distribution contains the LaTeX manuscript, seven data-generated figures, original experiment code, frozen numerical records, small native fixtures, archived methods, tests, and offline replay commands. It is a **working draft**, not a claim that the complete native particle/energy/spacetime mapping has been established.

The two proposed horizontal additions—pointlike electromagnetic production and beta-endpoint effective mass—remain **unexecuted**. They are not presented as results. No neutron is identified. The 11 GB late-universe corpus and its unfinished queue/RNG audits are not included or regenerated by the default workflow.

## Quick numerical reproduction

Python source syntax requires Python 3.10 or later. The supplied verification reports record the environment actually tested; exact synthetic draws are best replayed in that environment.

```bash
python -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python scripts/reproduce.py --suite compact
python -m unittest discover -s tests -v
```

On Windows, activate with `.venv\Scripts\Activate.ps1` in PowerShell instead of the `source` command. Dependency installation may require a network connection; the experiments themselves do not download data or call an API.

The compact run:

1. Reconstructs the actual 173-object bounded ideal and its 137-root registry with the original constructor.
2. Executes the original horizontal Cells 14 and 17–24, using their frozen parameters and embedded experimental transcriptions.
3. Recomputes Cells 32–34 from the saved Cell 29/26 histories and executes the finite instrument calculations of Cells 36–37.
4. Replays Cell 35's saved paths, counts, activity windows and collective certificates without generating its million-tick worlds.
5. Reexecutes self-contained Cells 38 and 39, including all new register-information calculations and synthetic inverse measurements.
6. Checks reference rational/discrete fields exactly and floating fields with explicit numerical tolerances. A single archive-appended validation field in Cell 17 is reported as archive-only, not silently claimed to be generated by its cell.

Outputs go to `build/replay/`, leaving frozen `data/reference/` files unchanged. The runtime is machine-dependent; there is no claim of a Mac benchmark.

For only the new vertical experiments:

```bash
python scripts/reproduce.py --suite new
```

For only the horizontal branch:

```bash
python scripts/reproduce.py --suite horizontal
```

## Regenerate the figures and compile LaTeX

```bash
python scripts/make_figures.py
python scripts/build_paper.py
```

Figure generation needs NumPy and matplotlib; it does not select candidates, optimize physics parameters, or refit a benchmark. It reads exact saved results, retaining failed controls and statistical distinctions. `paper/figures/SOURCE_MAP.json` records every figure's inputs and transformations.

The paper build requires a LaTeX installation providing **LuaLaTeX, Biber, and latexmk**, with the standard packages declared in `main.tex` and the Latin Modern fonts supplied by the TeX installation. No font files are distributed here. Alternatively, upload the `paper/` contents to an editor with those tools and select LuaLaTeX.

Direct compilation from `paper/`:

```bash
latexmk -lualatex -interaction=nonstopmode -halt-on-error main.tex
```

LaTeX is editable directly. `scripts/convert_markdown.py` is an **optional, overwriting** conversion-time helper requiring Pandoc; it rebuilds `main.tex` and the bibliography from the preserved draft and documented figure insertions. It is not needed for ordinary compilation and should not be run over manually edited LaTeX without saving those edits.

## Native-history and extended reproduction

```bash
python scripts/reproduce.py --suite native --output build/native_replay
```

This adds the original stochastic Cells 25, 26, 29, 30 and 31 before the remaining compact analyses. It takes substantially longer than the default run. It does **not** regenerate the large late neutron catalogue or the multi-million-tick Cell 35 campaign.

Cell 35 has a separate, explicit opt-in full generator:

```bash
python code/cells/DCU_Mass_Cell_35.py
```

That original cell needs a C++17 compiler, creates `DCU_Cell35_run/` relative to the current working directory, and can create roughly 2.3 GB of scratch event logs. The archive in `experiments/cell35/` contains the original complete small reproduction package, including its own README, C++ source, saved node tables, selected readouts and 512 confirmation readings. Do not interpret missing/censored windows as successful protection.

The self-contained Cells 38 and 39 can also be pasted individually into Jupyter. [`notebooks/new_verticals.ipynb`](notebooks/new_verticals.ipynb) provides a small wrapper that runs their original files without duplicating code.

## Evidence and release scope

A synthetic Born sample is not a laboratory measurement. The horizontal calculations borrow named physical laws and calibrations. The vertical channel borrows a complex representation, preparations, phase coupling and readout. Several native identities depend on general ancestry/exchangeable service, not uniquely on the S/I/G partition. The registry conditional-information graph is an exact instantiation under the stated independent first-write model, not an additional proof of physical necessity of 137.

Read [`REPRODUCIBILITY.md`](REPRODUCIBILITY.md) for the scope matrix and [`docs/PENDING_WORK.md`](docs/PENDING_WORK.md) for what remains open. Large late-catalogue summaries are included only as scoped exploratory evidence. Their raw-world reproduction is outside this compact distribution.
