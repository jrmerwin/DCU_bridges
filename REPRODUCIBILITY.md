## Numerical comparisons

- Fractions stored as `{numerator, denominator}` are compared as `Fraction` values. Fractions stored as strings are compared exactly.
- Discrete labels, node counts, events, outcomes and integer tables are compared exactly.
- Floating results use a comparison tolerance of `rel_tol=3e-10`, `abs_tol=3e-11` to accommodate platform/library summation differences. This tolerance is an implementation threshold, **not a physical error bar**.
- Callable helper functions cannot be serialized; expected empty helper dictionaries are not physics data. Cell 17's separate archived `validation` block was appended by its original independent validation, not returned by the original cell. It remains an explicitly reported archive-only field.
- The complete input files remain unchanged. `REPLAY_REPORT.json` identifies the checked leaf counts and any archive-only fields for each cell.
- Previous validation reports retain their original scope. Fresh release checks are named separately; none retroactively upgrades the partial late queue/RNG audits.

## Randomness and environments

Cells 38 and 39 use their original specified seeds and generators. The six new inverse-measurement states are checkpoints of two native trajectories; the 64 synthetic datasets per state are replicas conditional on that state. They are not independent universes or observational confidence intervals. Published data and previous fit comparisons remain historically dependent as documented.

`requirements-tested.txt` records the installed versions used here. Different Python or NumPy versions may differ in exact pseudorandom streams or floating reduction details. The replay fails loudly rather than selecting new seeds or silently replacing reference values. The Cell 35 compiled experiment uses its separately specified portable integer generator, not Python's random stream.

## Figures and paper

Seven figure scripts use the archived results without refitting. The source map names each input. SVG/PDF rendering can differ at the byte level across font/backend versions despite identical plotted values; numeric outputs and construction counts are the scientific comparison.

LaTeX output is not expected to be byte-identical across TeX distributions because engine metadata/font metrics may differ. The supplied release PDF was compiled, checked for unresolved citations and overfull boxes, and visually inspected. No third-party font files are included.

## Integrity

Run `python scripts/verify_manifest.py` before reproduction. `SHA256SUMS.txt` covers immutable distribution files. Build outputs, Python bytecode, TeX auxiliary files and the manifest itself are excluded. A matching digest checks file integrity, not scientific correctness.

## Historical code not on the paper replay path

The original Cells 01–16, 27 and 28 are retained as archival development context where available. Some raw notebook launch blocks require their original notebook state. They are not promised as separate standalone entry points. Use the unified runner and the independently self-contained/standalone experiments explicitly documented above. Their presence does not enlarge the scope of the release validation.
